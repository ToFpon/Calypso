Read your PDFs.
Change them too.

Calypso reads documents like GNOME Papers — same engine, Poppler — then lets you annotate them, fill in forms, check and add signatures, and organize, merge, compress, watermark, redact or protect them. Native GTK4 and libadwaita, following your desktop theme.

Reading

Everything Papers does, and it remembers

Each document reopens at the page, zoom and layout you left it with. The welcome page shows your recent documents; a small cross on hover removes one from the list.

Find, select, follow

  • Search ignores accents and case, results listed in the sidebar
  • Continuous or page by page, two pages side by side, zoom with Ctrl + wheel
  • Thumbnails, outline, links with a preview on hover, history back and forward
  • Rotation, night mode, full screen, presentation mode (F5), printing
  • Password-protected documents, automatic reload when the file changes

Your theme, light or dark

No colours of its own: Calypso follows Adwaita, your accent colour and your GTK4 theme.

Annotate · Forms · Signatures

Write on the document

Annotations and filled-in fields are saved into the PDF itself, readable by any other viewer. Ctrl+Z undoes, Ctrl+S saves — safely, never a half-written file.

Annotations

  • Notes, highlight, underline, strike out, squiggly underline
  • Rectangles and ellipses, six colours
  • Comment on any annotation, list them all in the sidebar

Forms and signatures

  • Text fields typed right on the page, check boxes, radio buttons, lists
  • Signatures checked when the document opens
  • Sign with your certificate (.p12 / .pfx import, or the certificates of Firefox)
Tools

The PDF tools of Odysseus, built in

The same engine as the Odysseus file manager (qpdf, Ghostscript). Results are written next to the document — never over an existing file.

Organize pages

Drag thumbnails to change the order, rotate, duplicate, delete, extract, split. Apply to the document, with Undo.

Watermark

Text or image, font, colour, opacity, angle, position, chosen pages — with a live preview. Flatten it so it cannot be removed.

⇄

Merge

Add other PDFs, set the order and the pages to keep from each.

↓

Compress

Ghostscript, four quality levels, grayscale option. Nothing written if it would not be smaller.

■

Redact

Draw the areas to hide: the text underneath is gone from the file, not just covered.

🔒

Protect

AES-256 password, print / copy / edit permissions, strong password generator. Remove it as easily.

Install

Two commands

Ubuntu 24.04 / 26.04, Zorin OS 18, Linux Mint 22 — updates then come with the system's.

$ sudo add-apt-repository ppa:nourpon/calypso
$ sudo apt update && sudo apt install calypso

Other Debian-based distributions (Debian 13…): download calypso_X_all.deb from the releases, then sudo apt install ./calypso_X_all.deb.
